# Sway for Windows

**Look. Focus. Flow.** A quiet system tray utility that switches keyboard focus to the monitor you are looking at,
using head pose from your webcam, entirely on-device.

This is the Windows port of [Sway for macOS](https://github.com/avimal5000/sway) (private). Status: planning. See
[PLAN.md](PLAN.md) for the build plan. No app code yet.
