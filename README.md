# Sway for Windows

**Look. Focus. Flow.** A quiet system tray utility that switches keyboard focus to the monitor you are looking at,
using head pose from your webcam, entirely on-device.

This is the Windows port of [Sway for macOS](https://github.com/avimal5000/sway) (private). Status: first release candidates. See [docs/INSTALL.md](docs/INSTALL.md) to install, and [PLAN.md](PLAN.md) for the
build plan.

## Legal

Sway collects no data and has no network code. See the [Privacy Policy](docs/PRIVACY.md) and the [Terms of Service](docs/TERMS.md). They apply to Sway for macOS and Sway for Windows.
