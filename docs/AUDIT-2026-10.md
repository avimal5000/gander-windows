# Sway for Windows: security and code-quality audit

Repo: /Users/avimalhotra/Developer/sway-windows (main, working tree clean). Read-only audit; nothing was built or run
(macOS host; the Windows-only code was read, not executed). Date of audit: 2026-10-30.

## Scope

All of `src/` (Sway.Core, Sway.Platform.Windows, Sway.App, Sway.Tools), `tests/` (file inventory and coverage gaps),
`scripts/` (privacy-guard.sh, audit-privacy.sh, fetch-pose-model.sh, soak.ps1 not reviewed in depth),
`.github/workflows/ci.yml`, `release.yml`, `dependabot.yml`, `Directory.Build.props`, csproj files, `app.manifest`,
`THIRD-PARTY-NOTICES.md`, `docs/PRIVACY-AUDIT.md`, `docs/INSTALL.md`, CLAUDE.md, CONTRACT.md (skimmed).

## Method

Read every Platform.Windows file and every Sway.App hosting file line by line; read the controller's camera lifecycle,
focus request, hotkey, library and settings paths; grepped the whole of `src/` for forbidden or risky APIs
(`GetWindowText`, `Process.Start`, `LoadLibrary`, `Assembly.Load`, `File.*`, `SetLastError`, `DefaultDllImportSearchPaths`,
telemetry, `SessionOptions`); verified P/Invoke struct sizes against the documented Win32 layouts by hand; reasoned
through thread and cancellation behavior. Findings marked "uncertain" could not be proven without running on Windows.

## Verified clean

- **Struct layouts** (`DisplayNative`): `DISPLAYCONFIG_PATH_INFO` 72 bytes, `MODE_INFO` 64 bytes, `DeviceInfoHeader` 20, `SOURCE_DEVICE_NAME` 84, `TARGET_DEVICE_NAME` 420 (`FriendlyName` 64 wchar, `DevicePath` 128 wchar), `MONITORINFOEX` 104, `WNDCLASSEXW` and `MSG` via `nint`: all match the Win32 definitions by hand calculation.
- **32-bit truncation**: monitor and window handles are carried as `long` via `ToInt64()`; `DisplayMapper` deliberately compares `unchecked((uint)handle)` against `NativeId` (monitor handles are 32-bit significant), with a rectangle fallback, so a collision cannot silently map wrongly.
- **Handles**: `OpenProcess`/`OpenProcessToken` closed in finally; icon `HICON` destroyed after clone (`TrayIconRenderer`); `CloseDesktop`, `WTSFreeMemory`, power-notification and WTS registrations unregistered on WM_DESTROY.
- **Delegate lifetime**: `WndProc` delegates are held in fields (`MessagePumpThread`, `WindowsSessionEvents`, `ForegroundWatcher`); `EnumWindows` callbacks are synchronous.
- **Elevation**: manifest is `asInvoker`, `uiAccess="false"`; audit script fails on `requireAdministrator`/`highestAvailable`/`uiAccess="true"`; `IsElevated` is only read to explain a failed focus. `Process.Start` is used once, for a constant `ms-settings:` URI.
- **No input capture or synthesis, no cursor APIs, no window titles, no networking**: grep of `src/` (including the spike tools) finds none; the only global input hook-like call is `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)`, which carries no input, and `RegisterHotKey`. The Run key value is the quoted exe path, compared with the same quoting; reads and writes are exception-guarded; value written only on user request.
- **Settings store**: atomic temp-then-replace; corrupt non-JSON or non-object files are copied to `.bak` and treated as empty (tested); `LastWriteError` surfaced; no secrets stored; values are numbers and names.
- **Camera release on lock/sleep/pause/quit**: designed through a serial operation chain, `SuspendTracker`, generation counters, and `QuitAsync`/`OnSessionEnding` (subject to F03); status events are re-validated by generation on the main thread.
- **Hotkey**: `RegisterHotKey` with `MOD_NOREPEAT`, one registration per action, conflict reported as state (`ShortcutInUse`), previous shortcut restored on failure.
- **Workflows**: CI has `contents: read`, uses `pull_request` (not `_target`), no secrets, no untrusted `${{ }}` in `run:`; release tag is regex-checked and `GITHUB_REF_TYPE` is verified before use; the model is hash-verified before it is moved into place and again in `audit-privacy.sh`; exactly one `.onnx` and an allow-listed native DLL set are enforced at publish time.
- **Manifest/DPI**: PerMonitorV2, good for physical-pixel monitor rectangles.
